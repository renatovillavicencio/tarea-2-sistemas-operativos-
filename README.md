# tarea-2-sistemas-operativos-
Simulación concurrente en tiempo real del juego Komikan (Tarea 2, Sistemas Operativos). Desarrollado en C/C++ mediante hilos, mutexes, semáforos POSIX y memoria compartida. Incluye servidor matchmaker para N jugadores, límite de M mesas simultáneas, árbitros de partida y manejo seguro de recursos (SIGINT)
